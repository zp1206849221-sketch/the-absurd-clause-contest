# The Absurd Clause Contest — Entry

A single line of deadpan legal boilerplate that quietly turns absurd: under
Section 14.3(b), clicking "agree" has already signed away, in perpetuity, all
rights in any tune hummed in the shower, any sneeze of unusual volume, and any
name devised for a pet not yet owned.

## Run

```sh
python3 main.py
```

This writes the clause (one line, 192 characters) to `/output/entry.txt`.
Requires only the Python 3 standard library.
